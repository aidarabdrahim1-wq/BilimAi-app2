# **App Name**: BilimAI

## Core Features:

- Personalized Study Plan Generator: Dynamically generate daily and weekly study plans for students based on their performance, weaknesses, and goals, leveraging an AI tool to prioritize topics and activities.
- Adaptive Diagnostic Testing: Conduct initial and periodic diagnostic tests that adapt to student responses to accurately identify weak subjects and topics, and measure speed versus accuracy.
- Comprehensive Learning Modules: Provide structured theory content grouped by subject and topic, accompanied by interactive practice tests and immediate feedback, including explanations for correct/incorrect answers.
- AI-Powered Mistake Analysis: Analyze student mistakes to identify patterns, frequently confused concepts, and provide targeted explanations, comparison cards, and personalized recommendations for improvement using an AI tool.
- Curator Chat Support: An AI chat interface offering calm, motivating, and disciplined support, addressing student messages, providing encouraging responses, and offering quick support actions.
- Holistic Progress Tracking Dashboard: Visualize student progress over time through an interactive dashboard displaying scores, study time, mistake rates, and goal achievement with charts and cards.

## Style Guidelines:

- Primary color: A sophisticated, deep indigo (#1F5BCD) symbolizing professionalism and focused study, providing a strong visual anchor on the light background.
- Background color: A very light, almost white, cool grey (#F7F9FA) with a subtle hint of blue, creating a clean, expansive canvas for content.
- Accent color: A vibrant yet elegant teal (#38ACC6) chosen to highlight key actions, interactive elements, and create an encouraging, fresh feel.
- Body and headline font: 'Inter' (sans-serif) for its modern, objective, and highly readable qualities, ensuring professional clarity across all content.
- Use a professional, clean, line-iconographic style with subtle, subject-specific educational illustrations for engagement without distraction.
- Employ a modern, card-based layout with rounded corners and subtle soft shadows within a clean grid system, ensuring strong visual hierarchy, generous balanced spacing, and mobile responsiveness. Implement sticky top navigation and clear sidebar for intuitive global navigation.
- Subtle and smooth transitions for page loads, navigation, and state changes (e.g., button hovers, chart updates), enhancing the user experience without being disruptive or playful.
